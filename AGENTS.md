## UI Reference Screenshots

Wanderlog UI screenshots are stored in:

design_reference/wanderlog/

These images are visual inspiration for the YatraCanvas frontend.

Before creating or significantly redesigning a screen, inspect the relevant screenshots in this directory.

Use them to understand:

- spacing
- hierarchy
- rounded-card layouts
- large headings
- progress indicators
- selection controls
- bottom CTA placement
- navigation patterns
- map/itinerary presentation

Do NOT:

- copy Wanderlog branding
- copy its logo
- reproduce screens pixel-for-pixel
- reuse Wanderlog-specific marketing content
- imitate its exact colors

YatraCanvas must maintain its own visual identity.
